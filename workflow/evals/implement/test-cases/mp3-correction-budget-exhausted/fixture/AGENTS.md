# Fixture guidance

This is an orchestration exercise with controlled dependency skills, not a live
QuizIt application. Use the injected stage skills and their executable adapters;
there are no application installs or live services. Preserve scripts, task briefs,
specs and teammate work. Stage adapters may update src/selected.txt and write their
assigned workflow artifacts. Use logs/eval.md for Eval owner's interaction summary.
Commit proposals only; no staging, Git history/branch changes or remote actions.
